# 208 with me

본서사: 1997년 6월 30일, 홍콩 카이탁 → 시드니. 임완청 · 이공팔.

들어오면 먼저 **탑승권**이 뜨고, 바코드 부분을 누르거나 당겨 **절취선을 뜯으면** 몽콕 ~ 삼수이포 지도로 들어가요. 지도 위 점을 누르면 **창**(성향표 / 페어 / 버닝 중 / 연결)이 열려요.

점 하나 = 창 하나. 기본으로 세 개가 들어 있어요.

| 점 | 창 |
| --- | --- |
| 성향표 | 기본 정보, 성향 슬라이더, 호불호(O △ X), 좋아하는 것 / 싫어하는 것, 소개, 메모 |
| 페어 | 페어 카드 목록 → 누르면 페어 소개 (서로에게, 관계 수치, 연표, 대사, 소개) |
| 버닝 중 | 증명사진 카드 목록 (불꽃 0~5, since) → 내용이 더 있으면 누르면 자세히 |

```
index.html        뼈대 (거의 안 건드려도 됨)
data.js           ← 내용은 전부 여기서 고침
assets/style.css  디자인
assets/app.js     동작
assets/vendor/    지도 라이브러리 (Leaflet)
```

## 내용 고치기 — `data.js`

- `site` — 탭 제목, 왼쪽 위 지명, 기본 색, 찢는 소리 on/off, `passenger`(탑승권 출발지 = 나)
- `opening` — 들어오면 먼저 뜨는 탑승권(히어로). 뜯으면 지도로. `show`: `"session"` 한 번 / `"always"` 매번 / `"off"`
- `playlist` — 왼쪽 아래 음악 (유튜브 주소의 `v=` 뒷부분)
- `pages` — 지도 위 점들. 하나씩 `type`을 고르면 돼요.
  - `"profile"` 성향표 · `"pairs"` 페어 · `"chars"` 캐릭터 목록 · `"note"` 자유 글
  - `label`은 지도·메뉴·창 제목에 쓰이는 이름
  - `ticket.to`는 창 위쪽 FROM → TO 줄의 도착지 (장소 코드, 이름 등)
  - 점을 누르면 그 자리에서 창이 펴져요. `card: "label"`인 점은 체크인 카드부터

팁

- 필요 없는 칸은 지우면 창에서도 사라집니다.
- **점 더 만들기**: `data.js` 맨 아래 주석 처리된 `공지` 예시를 참고해서 `pages`에 하나 더 붙이면 끝.
- **좌표**: `lat`, `lng`를 지우면 몽콕~삼수이포 안 아무 데나 알아서 자리 잡아요(다른 점과 안 겹치게). 직접 정하고 싶으면 구글 지도에서 우클릭 → 맨 위 숫자(`22.32, 114.16`)를 복사.
- **사진**: `assets/img/` 폴더에 넣고 `photo: "assets/img/gongpal.webp"`처럼 적기. 비우면 실루엣.
- **서사**: 페어의 `story`에 `{ when, title, text, notes }`를 한 칸씩. 페어 창 아래 STORY로 나와요.
- **음악**: `site.autoplay: true`면 처음 누르는 순간(탑승권 뜯을 때) 바로 재생. 브라우저가 소리 자동재생을 막아서 접속만으로는 못 틀어요.
- `about` · `notes` · `text`에는 HTML도 됩니다. `<a href="#pairs/1">`처럼 쓰면 누를 때 그 창이 열려요.
- 주소 끝에 `#아이디`(예: `.../#burning`, `.../#pairs/2`)를 붙이면 그 창이 바로 열립니다. 공유용.

## 사이트 안에서 바로 글자 고치기 — `?edit`

주소 끝에 `?edit`를 붙여 들어가면 편집 모드예요. (예: `https://208with.me/?edit`, 내 컴퓨터에선 `index.html?edit`)

1. 빨간 점선이 있는 글자를 누르고 그대로 고치기 — 탑승권, 창 안 글자, 왼쪽 위 지명 전부
2. 위 검은 줄의 **data.js 저장** → 고친 내용이 들어간 `data.js`가 내려받아져요
3. GitHub 저장소에서 `data.js` → 연필(Edit) 대신 *Add file → Upload files*로 받은 파일을 올려 덮어쓰기 → Commit

- 고치던 건 브라우저에 임시 저장돼서 새로고침해도 남아 있어요. **되돌리기**를 누르면 원래 `data.js` 상태로.
- **탑승권** 버튼: 오프닝 탑승권을 다시 띄워서 고치기
- 줄바꿈은 소개(`about`)처럼 긴 글 칸에서만 됩니다. 짧은 칸은 Enter = 끝내기.
- 숫자(슬라이더 %, 불꽃 개수, 관계 수치), 사진, 칸 추가/삭제, 좌표는 아직 `data.js`에서 직접.
- 편집 모드는 `?edit`로 들어온 나한테만 보여요. 방문자 화면은 그대로.

## 오프닝 탑승권

바코드 부분을 **아래로 당기거나**, 절취선을 따라 **옆으로 쭉 밀면** 왼쪽부터 절취선 구멍을 따라 조금씩 찢어지고, 끝까지 가면 떨어져 나가면서 지도로 들어가요. (Enter / ESC 로도 뜯어짐)

## 연결 점 (CAPTCHA 기믹)

`type: "captcha"` 점을 누르면 "I'm not a robot" 체크 상자가 떠요. 체크 → 문제가 펼쳐지고 → ⟳ 를 누르면 옆 홈으로 넘어가고 → **Verify** 를 누르면 그 홈이 새 탭으로 열려요. 🎧 는 음악 재생/정지.

`data.js`의 `links`에 한 줄씩: `url`(주소) · `label`(보이는 주소) · `words`(비뚤비뚤 글자) · `answer`(입력칸에 저절로 쳐지는 답)

## 체크인 카드 (페어 점)

페어 점을 누르면 옛 홍콩 호텔 짐 라벨 모양의 체크인 카드가 떠요. 카드를 누르면 빨간 도장(CHECKED IN · 1997.06.30)이 쾅 찍히고, 카드가 그대로 펴지면서 페어 창이 열려요.

- 그림은 `assets/label.svg` — 옛 홍콩 東山酒店 짐 라벨을 따라 그려 벡터로 바꾼 것. 배경 흰색, 맨 위 한자는 **八寶丸子**(원본처럼 오른쪽에서 왼쪽으로 읽음).
- 어느 점에 쓸지는 `pages`에서 `card: "label"`로 (다른 점에도 붙일 수 있어요). 도장 글씨 · 날짜는 `data.js`의 `label`에서 (`stamp`, `date`).
